One platform, six components

Vera Rubin joins the 88-core Vera Arm CPU, Rubin GPU, NVLink 6 switches, ConnectX-9 SuperNICs, BlueField-4 DPUs and Spectrum-6 Ethernet. Vera and Rubin share a coherent memory view over 1.8 TB/s NVLink-C2C.

  • DGX Vera Rubin NVL72: 72 GPUs + 36 CPUs; 3.6 EFLOPS NVFP4 inference and 2.5 EFLOPS training per rack.
  • Spectrum-6: 102.4 Tb/s switch capacity; silicon-photonics options target lower optical power.
  • Quantum-X: 144×800G ports, 115.2 Tb/s aggregate.
  • Next: Rubin Ultra / Kyber NVL576 in H2 2027; Feynman + Rosa CPU follows in 2028.

02 / TRAINING

Two training stacks, one agentic-RL thesis

NeMo RL is the production path; Molt is the compact research path. NeMo Gym and Polar supply the environments and token-faithful experience that both paths need.

Production stack

NeMo Framework + RL + Gym

Framework 26.x builds on PyTorch and Megatron-Core with 5D parallelism, FP8/MXFP8 and MoE parallel folding. NeMo RL supports PPO, DPO, REINFORCE/GRPO, GDPO, MOPD and CISPO. Gym v0.6 adds external harnesses during RL with exact token-ID preservation and rollout diagnostics.

Research stack

Molt: ~9K lines, frontier scale

Ray handles placement and an asynchronous queue; vLLM generates rollouts; NVIDIA AutoModel + FSDP2 trains the policy. The stack supports REINFORCE, RLOO, GRPO, Dr.GRPO and GAE, plus optional PPO critic and on-policy distillation.

Train / infer consistency

Never train on foreign tokens

Async scale

Overlap rollout and learning

Molt’s distributed experience store removes a central memory bottleneck; Polar’s gateways prewarm runtimes, execute agents, evaluate and callback asynchronously.

Acceleration

Speculative decoding

NVIDIA reported 1.8× rollout-generation speedup at 8B and projected 2.5× end-to-end at 235B, while computing training signals against the verifier policy.

Important tension

Process alignment ≠ benchmark success

Adding a GPT-6 Astra judge score at weight 0.2 raised preference for rubric-aligned trajectories to 73.0% versus 24.0% for base, yet produced smaller benchmark gains. The paper exposes a central open problem: optimizing task completion can diverge from following the expert process.

Reproducibility note. The report has no confirmed canonical arXiv ID, and its full author list was not verified. The prior reproduction attempt found the public SkillHub release contains 2,396 skills and was regenerated with a different model for legal reasons; the private S2EBench and 15,968 GLM-5.3 trajectories were not published. The headline 300-step 27B result therefore cannot be independently recreated from public artifacts alone.

04 / SERVING

Dynamo makes inference a distributed control problem

Agent workloads are long, bursty and KV-heavy. NVIDIA’s answer is to split phases, route requests with cache awareness and treat memory as a tiered system.

Encode / prefill

Separate GPU pool builds the prompt’s KV state.

→

KV-aware router

Routes around cache locality, queue state and agent hints.

→

Decode

Dedicated pool generates tokens; memory can spill to S3 or Azure tiers.

Dynamo 1.0 · GA 16 Mar

Inference operating layer

Open source, adopted by major clouds and reported in production at Perplexity, PayPal, Pinterest and Cursor. NVIDIA cites 7× requests served on Blackwell in SemiAnalysis InferenceX using DeepSeek R1-0528.

NIM 2.x

Packaged model services

OpenAI-compatible container APIs bundle nim-llm, nimlib and vLLM; optimized profiles historically use TensorRT-LLM. Development is free through the Developer Program; enterprise containers are proprietary.

TensorRT-LLM 1.x

Peak-performance backend

The PyTorch workflow is now the default experience, but the C++ runtime was open-sourced—not deprecated. July releases added EAGLE3 and fused kernels; GPT-OSS received day-zero support in August.

Agent-specific advantage.

“Agent hints” communicate latency sensitivity and expected output length. Combined with NeMo Agent Toolkit, NVIDIA reports 4× lower time-to-first-token and 1.5× throughput on Llama 3.1/Hopper. Persistent KV caching helps repeated system prompts, RAG and multi-turn loops.

08 / SECURITY

Security moves into the runtime

NVIDIA’s 2026 security story is tooling-led rather than paper-led: constrain execution, mediate model interactions, classify content, then attack the assembled system.

1 · Isolate

OpenShell applies Landlock, seccomp, network namespaces, deny-by-default file/network permissions, live policy updates and audit trails. NeMo Gym also supports Apptainer, Docker, Enroot, Daytona, Fargate and OpenSandbox.

2 · Mediate

NeMo Guardrails provides input, dialog, retrieval, execution and output rails. Colang 2.0 is the recommended event-driven DSL; IORails intercept OpenAI-style tool calls.

3 · Classify

NemoGuard NIMs package content-safety and topic-boundary classifiers for production. Nemotron-3.5 Content Safety arrived in June.

4 · Attack

garak offers 120+ probe families spanning jailbreaks, encoding attacks, data leakage, prompt injection and tool misuse. NeMo Agent Toolkit adds workflow-level red-team scenarios.

Lifecycle control

NemoClaw posture profiles

Development, internal and production profiles package the agent lifecycle around blueprints, routed inference and policy. Canonical and Red Hat are integrating OpenShell.

Context

External red-team tools

Microsoft PyRIT and Confident AI DeepTeam cover automated multi-turn attacks and broad vulnerability taxonomies; OWASP LLM Top 10 remains the shared language for risk.

Research gap. This sweep found no NVIDIA 2026 research paper specifically devoted to prompt-injection or tool-use defenses. The substantive story is the integrated toolchain above. NeMo Guardrails’ exact latest version also conflicted across sources (0.21.x versus 0.24), though active development is clear.

09 / SYNTHESIS

Eight directions to watch

These are inferences from the integrated roadmap—not separately announced product commitments.

Environments replace preference labels

Tool execution, tests and judges become the dominant source of scalable reward for agents.

Skills become training infrastructure

Expert-authored instructions are compiled into executable worlds, pushing research toward better generation gates and credit assignment.

Train the exact harness that ships

Polar’s proxy pattern points toward framework-agnostic RL over production agent loops, not simplified lab replicas.

Small stacks challenge giant frameworks

Molt argues that auditable, ~9K-line research systems can still reach frontier-scale policies.

Inference becomes the agent bottleneck

Disaggregated prefill/decode, KV tiers and speculative decoding target the cost of long-horizon, multi-turn rollouts.

NVFP4 becomes the economic default

Rubin silicon, TRT-LLM kernels and Nemotron checkpoints align around 4-bit throughput per dollar.

Agent RL crosses into physical AI

Cosmos and GR00T connect verifiable environments, simulation and action generation for robotics and autonomous vehicles.

Safety becomes an infrastructure primitive

Sandbox policy, runtime interception and adversarial evaluation move from optional wrappers into the default deployment shape.

What is strong

The research program is unusually coherent: the same teams connect environments, harness capture, asynchronous rollout, compact training and optimized serving. Several core projects are Apache-2.0 with published papers and code.

What remains unproven

Many performance figures are vendor claims; Skill2Env’s strongest result is not fully reproducible from public assets; process alignment still conflicts with benchmark success; and the security agenda lacks a comparable 2026 research-paper centerpiece.

10 / OPEN QUESTIONS

What the evidence does not settle

A roadmap is most useful when its uncertainties remain visible.

SKILL2ENV

Can a legally reproducible public dataset recover the reported RL gains, and can S2EBench or an equivalent held-out benchmark be released?

REWARD DESIGN

How should systems combine test success and process compliance without sacrificing either?

HARNESS EFFECT

Polar’s gains vary from +22.6 to +0.6 points across harnesses. Which harness behaviors cause the spread?

SERVING ECONOMICS

Do Dynamo’s 7× and Rubin’s 10× cost-per-token claims hold across real multi-agent workloads and independent benchmarks?

SECURITY

Can sandboxing, runtime rails and scanning stop cross-layer attacks involving prompt injection, tools and persistent agent state?

LICENSING

Will custom model licenses slow enterprise composition even as the surrounding infrastructure remains open source?
